## 摘要
基于扩散的无监督域适应（UDA）通过为下游适应生成目标域特定的合成数据来提升跨域迁移性能。现有方法大多面向单目标域适应设计：当在一个有标注源域上训练的模型需要适应多个无标注目标域时，它们通常需要为每个源-目标域对分别进行扩散微调，导致训练、存储和部署成本随目标域数量增长。本文研究基于扩散的UDA中的多目标数据生成，即复用单次源引导的扩散微调过程，为多个目标域生成目标域特定的合成数据。我们提出MUSE（Multi-target UDA-oriented Synthesis with Efficient diffusion fine-tuning，面向多目标UDA的高效扩散微调合成），一种解耦式适应框架，将源监督的语义适应与目标域特定的风格适应分离。MUSE使用由有标注源数据更新的共享语义分支和针对各个目标域的私有风格分支，从而在实现目标域特定生成的同时，避免为每个目标域重复进行源引导微调。在标准UDA基准上的实验表明，与逐目标域重复扩散适应相比，MUSE实现了更强的精度-效率权衡，在降低扩散微调成本的同时提升了目标域平均精度。项目页面：https://xuanqi99.github.io/MUSE/。

## Abstract
Diffusion-based unsupervised domain adaptation (UDA) improves cross-domain transfer by generating target-specific synthetic data for downstream adaptation. Existing methods are largely designed for single-target adaptation: when a model trained on one labeled source domain must be adapted to multiple unlabeled target domains, they typically require separate diffusion fine-tuning for each source--target pair, causing training, storage, and deployment costs to grow with the number of targets. In this paper, we study multi-target data generation for diffusion-based UDA, where a single source-guided diffusion fine-tuning process is reused to generate target-specific synthetic data for multiple target domains. We propose MUSE (Multi-target UDA-oriented Synthesis with Efficient diffusion fine-tuning), a decoupled adaptation framework that separates source-supervised semantic adaptation from target-specific style adaptation. MUSE uses a shared semantic branch updated by labeled source data and target-private style branches specialized to individual target domains, enabling target-specific generation while avoiding repeated source-guided fine-tuning for each target. Experiments on standard UDA benchmarks show that MUSE achieves a stronger accuracy--efficiency trade-off than repeated per-target diffusion adaptation, reducing diffusion fine-tuning cost while improving average target-domain accuracy.
