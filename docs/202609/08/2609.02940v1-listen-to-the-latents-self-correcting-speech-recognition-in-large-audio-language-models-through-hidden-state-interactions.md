## 摘要
近年来，自动语音识别（ASR）系统越来越多地集成大型语言模型（LLM），以利用其语义知识，无论是通过逻辑融合外部集成，还是通过热启动内部集成。然而，如何有效结合这两种策略仍未得到充分探索。在本工作中，我们通过利用模型自身的预适应基础LLM来优化热启动的基于LLM的ASR模型，重点关注基础LLM得以保留的LoRA适应设置。为此，我们提出了混合搜索，这是一种针对性的纠正策略，受两个观察结果启发。首先，表征基于LLM的ASR隐藏状态与基础LLM隐藏状态之间关系的交互特征，为令牌的语义依赖程度提供了信息丰富的信号。其次，选择性地优化具有高语义依赖性的目标令牌，其ASR性能提升远超朴素的全局LLM纠正方法（包括重打分和晚期融合）。我们的分析表明，即使在通过热启动实现语义知识迁移之后，基于LLM的ASR模型仍可利用其基础LLM进一步提升推理时性能。

## Abstract
Recent automatic speech recognition (ASR) systems increasingly integrate large language models (LLMs) to leverage their semantic knowledge, either externally through logit fusion or internally through warm initialization. However, how to effectively combine these two strategies remains underexplored. In this work, we refine warm-initialized LLM-based ASR models by leveraging their own pre-adaptation base LLMs, focusing on LoRA-adapted settings where the base LLM is preserved. To achieve this, we propose Hybrid Search, a targeted correction strategy motivated by two observations. First, interaction features that characterize the relationship between LLM-based ASR hidden states and base-LLM hidden states provide informative signals about a token's degree of semantic dependence. Second, selectively refining targeted tokens with high semantic dependence improves ASR performance far beyond naive global LLM-correction methods including rescoring and late fusion. Our analysis suggests that, even after semantic knowledge transfer through warm initialization, LLM-based ASR models can still leverage their base LLM to further improve inference-time performance.

## 二、方法论

### 1. 核心思想
- 利用 LoRA 微调后的 ASR-LLM 隐藏状态轨迹（H_ASR-LLM）与其原始基础 LLM（H_LLM）在相同文本上下文下产生的隐藏状态轨迹之间的**几何关系**（余弦相似度 + 相对模长），构建二维"交互特征"，用于判别该 token 的**语义依赖程度**。
- 基于此特征判定高语义依赖 token（以命名实体为代表），只对这部分 token 采用 LLM 概率融合 + 束搜索扩展，而非全局 LLM 纠正，从而实现**自纠正**（self-correction）。

### 2. 关键技术细节

**(1) 特征提取与定义**

模型表示为 f = f_head ◦ f_L ◦ … ◦ f_1 ◦ f_emb。定义如下特征：

- **AngleFeat**(l, i) = cos( h_ASR-LLM^(l,i), h_LLM^(l,i) )
- **MagFeat**(l, i) = ||h_ASR-LLM^(l,i)||₂ / ||h_LLM^(l,i)||₂

**(2) 层相分析：三层分段**

通过对 YODAS 上 Phi-4-Multimodal 的特征轨迹分析，将层划分为：

| 层段 | 现象 |
|---|---|
| 早层（0–7） | 特征值接近 1，方差极小，可区分性差 |
| 中层（8–28） | 方差大，命名实体 token 呈现峰值状高 AngleFeat 与高 MagFeat，分布偏移明显 |
| 晚层（29–32） | AngleFeat 下降、MagFeat 上升，偏移弱于中层 |

因此最终取**中层特征**：在层 10–28 内取 top-3 最大均值聚合为 AngleFeat_inter 与 MagFeat_inter。

**(3) 目标 token 选择**

- 对每个 token 得到二维特征 z_i = (AngleFeat_i, MagFeat_i)。
- 通过高斯密度比做判决：

  T(x_i) = 1[ P_NE(z_i) / P_nonNE(z_i) ≥ τ ]

  其中 P_NE、P_nonNE 为 YODAS 上拟合的命名实体/非命名实体的二维高斯分布；τ=1 为等密度边界，τ=1/2 为更宽松的边界。
- 多 token 词仅对续接 token 判定；判定后扩展到整个词。
- 推理阶段不需要外部 NER 模型，仅依赖隐藏状态特征。

**(4) Hybrid Search 解码算法（算法流程）**

- 核心机制：在**贪心搜索**与**束搜索**之间动态切换，混合两种解码方式。
- 处理流程：
  1. 初始为贪心搜索状态（有效束大小 K=1）；
  2. 解码每一步后检测当前 token 是否为目标 token：
     - 若是且当前为贪心状态，切换到束搜索（束大小 B=5）；
     - 若当前处于束搜索状态，且所有束分支在某个非目标 token 上达成一致，则将该一致非目标位置设为汇聚点，回滚各束至此位置，选取最优候选，将状态切回贪心搜索；
  3. 重复直至序列结束。

**(5) 概率融合**

对数概率按分段函数更新：

- 目标 token：(1−α) log p_ASR-LLM + α log p_LLM
- 非目标 token：log p_ASR-LLM

默认 α = 0.2，τ = 1/2，B = 5。

## 三、实验设计

### 1. 数据集与 Benchmark
- **主评估集（Open ASR Leaderboard）**：AMI、Earnings22、GigaSpeech、LibriSpeech、SPGISpeech、TED-LIUM、VoxPopuli 共 7 个子集。
- **额外鲁棒性集**：Common Voice。
- **特征校准集**：YODAS 数据集（用于上文中高斯密度拟合的标注来源是由 BERT NER tagger 标注命名实体）。
- **评估指标**：
  - WER（词错误率）
  - NE-ER（命名实体错误率）——按 BERT NER tagger 识别命名实体词后计算不得配比例，弥补 WER 对语义重要性关注不足的问题。
  - 统计显著性：采用双向精确 McNemar 检验。

### 2. 对比方法
| 类别 | 方法 |
|---|---|
| 基线解码方式 | Greedy Search、Beam Search（B=5） |
| 既有 LLM 纠正方法（外部） | GER ⇒ Parakeet、Neko Qwen1.5-MoE、Speech-Hands ⇌ Parakeet（均报告最佳结果） |
| 朴素全局 LLM 纠正（内部） | 对 Beam Search 结果做 Rescoring、对解码过程做 Late Fusion |
| 消融变体 | Hybrid Search (τ=1); Hybrid Search (τ=1/2); Hybrid Search (τ=0，仅多 token 词目标化，剔除中间层特征); Hybrid Search without LLM Correction（设 α=0） |
| 模型 | 主模型 Phi-4-Multimodal；泛化验证 Granite-4.0-1B-Speech |

### 3. 两种实验设置模式
- **Hybrid Search for Decoding**：单遍解码，直接从 Greedy 出发运行算法。
- **Hybrid Search for Error Correction**：两遍流程（先 Beam Search 获得假设，再基于该假设做第二遍 refinement，非目标位置做 teacher forcing），可视为测试时扩展方法。

## 六、主要结论与发现

1. **隐藏状态交互特征（AngleFeat、MagFeat）确实能区分 token 的语义依赖程度**——命名实体（特别是多 token 词的续接 token）在 ASR-LLM 与基础 LLM 对比中系统性表现出高余弦相似度、高相对模长。
2. **目标化纠正优于全局纠正**：统一对所有 token 做 LLM 融合（Late Fusion）会严重伤害 WER（6.36 → 9.11）；仅对高语义依赖 token 做融合则带来实质收益，且不产生幻觉风险。
3. **Hybrid Search for Decoding 高效取得接近 Beam Search 的效果**：在约 1.4× 贪心成本的平摊开销下，恢复了 Greedy→Beam WER 增益的 25%、NE-ER 增益的 96.4%——且去掉 LLM 纠正后 NE-ER 增益降至 68.3%，说明搜索扩展与 LLM 语义信息二者均有贡献。
4. **Hybrid Search for Error Correction 在 Beam Search 基础上进一步改善 NE-ER**：平均 NE-ER 从 18.29% 降至 17.69%（TED-LIUM 相对提升 12.7%、SPGISpeech 相对提升 8.8%），同时 WER 不降（统计上显著）。
5. **τ=0（仅凭词表面形式做多 token 词目标化）无法保持 Beam Search 的 WER 鲁棒性**，证明中间层隐藏状态特征对目标化决策不可或缺。
6. 热初始化后的 ASR-LLM 仍然出现了部分语义知识遗忘（或未充分利用），基础 LLM 在推理期仍有可开发的剩余语义知识。

## 七、方法或实验设计优点

1. **方法新颖且简洁**：
   - 仅使用两个简单标量（余弦相似度、相对模长）构建跨模态（语音-文本条件）的 token 级隐藏状态交互描述子，以直观可解释的方式刻画 ASR 语义依赖度。
   - 特征提取开销仅约 10⁶ FLOPs/位置，相对模型前向开销可忽略。
2. **自纠正范式无需额外模型**：
   - 不需要外部 NER 标注器参与推理，不增参、不再训练，完全利用 ASR-LLM 与其内部基础 LLM 自身实现推理时自纠正，比既有 agentic 纠正管道更轻量。
3. **高效解码设计**：
   - Hybrid Search 在贪心与束搜索之间动态切换的工程机制设计巧妙，以"目标 token 触发束展开 + 束间达成一致的非目标 token 作为汇聚回滚点"的方式处理分数尺度不统一问题，在实际吞吐上以 1.4× 的成本逼近 Beam Search 增长收益。
4. **指标互补性好**：
   - 用 WER + NE-ER 双指标组合来评估，正确回应了"LLM 语义增益难以在 WER 中显现"这一评估陷阱。
5. **分析链条完整**：
   - 从层相动力学特征观察 → 分布建模 → 目标化校正算法 → 消融验证 → 人工案例检查，形成完整闭环，且加入了两种模型的验证来确认特征规律的一般性。
6. **统计严谨**：
   - 双侧精确 McNemar 检验覆盖各数据集与指标的结果，显著性判断细致明确。

## 八、不足与局限

1. **完整方法验证范围小**：
   - 端到端 Hybrid Search 仅在 Phi-4-Multimodal 上验证；Granite-4.0-1B-Speech 上只做了特征分布规律验证，完整纠正算法的泛化性尚待检验。
2. **特征与阈值依赖模型**：
   - 二维高斯分布、层聚合策略（层 10–28 的 top-3 均值）、τ 阈值等需要针对模型重新标定，难以直接迁移到其他架构；对闭源系统（无法访问中间隐藏状态）完全不可用。
3. **数据集的多样性有限**：
   - 虽覆盖了 Open ASR Leaderboard 共 8 个子集，但均为英语语音为主，未覆盖多语言场景；更极端的应用场景（如歌唱 ASR、强噪声干扰等）文中明确承认可能还需要额外标定。
4. **计算成本分析维度偏窄**：
   - 只报告了平摊解码 FLOPs 的相对倍数（1.4×），未报告模型绝对运算量、实际推理延迟、显存占用以及两遍流程（Error Correction 设置）的额外绝对开销；对 GPU 资源、训练/推理算力也未做披露。
5. **校准依赖潜在偏差**：
   - 特征分布拟合与 NER 标注均基于 YODAS/BERT NER tagger，存在标注噪声与语料分布偏差向方法传播的风险。NER tagger 的识别错误可能污染 NE-ER 的评测合理性。
6. **概率插值权重 α 等超参数**在不同数据上没有逐一调优，统一取 α=0.2，可能无法在所有数据集上达到该设定下的最优效果；τ=0 与 τ=1/2、τ=1 的性能差异也表明阈值较为敏感。
7. **消融中去除 LLM 纠正仍能保住 68.3% 增益**，说明无法完全排除"较多收益来自搜索扩展（搜索本身发现更好假设）"而非 LLM 语义信号的可能性，论文对这一混淆因素的解释尚不充分。
